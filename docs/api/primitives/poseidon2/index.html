primitives.poseidon2#

Poseidon2 hash over BabyBear via Rust FFI.

Wraps Plonky3’s production Poseidon2BabyBear<16> permutation.

Reference:

p3-symmetric (PaddingFreeSponge, TruncatedPermutation).
