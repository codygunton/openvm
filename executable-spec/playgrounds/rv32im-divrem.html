RV32IM Divide / Remainder

The DivRemCoreAir is the most complex instruction in RV32IM. Division is hard to constrain directly, so instead we verify the equation b = c × q + r and prove r < c (proper remainder). This turns a division problem into multiplication (which we know how to constrain) plus a comparison.
Division by Verification
Instead of dividing, the prover provides q (quotient) and r (remainder) as witnesses, then constrains: (1) b = c*q + r via polynomial multiplication, (2) 0 ≤ r < c via a less-than check. If both hold, then q = b/c and r = b%c.
Edge Cases
Division by zero: RISC-V spec says b/0 = 0xFFFFFFFF and b%0 = b. Signed division: signs of q and r follow RISC-V conventions (q_sign = b_sign XOR c_sign when q≠0).

  • C9 Special case flags zero_divisor + r_zero ∈ {0,1} always

Division Equation: b = c × q + r

Edit q[i] or r[i] limbs below to see which constraints break. 0 = satisfied, nonzero = violated.

Limb-by-Limb Verification (Lower 4 Limbs)

Constraints C1-C4: For each limb i, compute cross-product sum of c*q at position i, add r[i] and carry from previous limb. The result mod 256 must equal b[i], and the quotient is carry[i].

Upper Limb Carry Chain (Sign Extension)

The upper 4 limbs of the full 8-limb product c*q+r must all equal the sign extension of b. For unsigned ops, this means they must be zero. For signed ops, they must be 0xFF if b is negative.

Remainder Bound: r_prime < c

Constraint C6: Scan from MSB to LSB to find first limb where r_prime and c differ. At that limb, c must be strictly greater (unsigned case) or r_prime must be strictly greater (signed negative c case).
