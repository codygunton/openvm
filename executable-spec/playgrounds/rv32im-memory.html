RV32IM Load / Store

Load and store instructions move data between registers (4 bytes) and memory at byte/halfword/word granularity. The key challenge is alignment: a halfword load from an odd address must shift and mask bytes correctly. Stores must merge new data into the existing register/memory word without corrupting adjacent bytes.
Concepts
Byte Masking
A LB (load byte) reads 4 bytes from memory but only keeps 1, zero-extending the rest. A LH (load halfword) keeps 2 bytes. The shift amount (0-3) selects which byte(s) to extract from the 4-byte word.
Sign Extension
LB and LH (signed variants) extend the sign bit of the loaded value to fill the upper bytes. If the MSB of the loaded byte is 1, the upper bytes become 0xFF. LBU and LHU (unsigned) zero-extend instead.
Store Merging
A SB (store byte) must write 1 byte into a 4-byte word without changing the other 3 bytes. The prev_data column holds the original word, and write_data is constructed by inserting the new byte at the correct position.

Constraints
  • C1 is_valid boolean, is_load from opcode is_valid ∈ {0,1}, is_load = (op is L*) all ops
  • C2 LW: write = read (direct copy) write[i] = read[i] for i=0..3 LW
  • C3 LH/LHU: extract 2 bytes at shift write[0]=read[s], write[1]=read[s+1], upper=0 or sign LH / LHU
  • C4 LB/LBU: extract 1 byte at shift write[0]=read[s], upper bytes=0 or sign LB / LBU
  • C5 SW: write = register (direct copy) write[i] = reg[i] for i=0..3 SW
  • C6 SH: merge 2 register bytes into prev write[s]=reg[0], write[s+1]=reg[1], rest=prev SH
  • C7 SB: merge 1 register byte into prev write[s]=reg[0], rest=prev SB

Memory Word (read_data)

The 4 bytes read from memory. Edit hex values (00-FF).

Register Data (for stores)

The 4 bytes from the source register. Used by store operations.

Previous Memory Word (prev_data)

The existing 4 bytes at the destination address before the store. For SB/SH, unmodified bytes come from here.

Byte Selection (shift = 0)

Which bytes from read_data are selected for the result.

Sign Extension

Signed loads (LB, LH) extend the MSB of the loaded value into the upper bytes.

Store Merge

New register bytes are inserted at the shift position; other bytes are preserved from prev_data.

Constraint Evaluation

Edit write_data bytes to see which constraints break. 0 = satisfied, nonzero = violated. Modified cells are highlighted.
