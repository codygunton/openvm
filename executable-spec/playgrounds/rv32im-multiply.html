RV32IM Multiply

The MultiplicationCoreAir computes the lower 32 bits of the product of two 32-bit values. Each value is represented as 4 limbs of 8 bits. Multiplication uses schoolbook polynomial multiplication: the product of limbs generates cross-terms that accumulate with carries. The MULH variants compute the upper 32 bits with sign extension.
Schoolbook Multiplication
To multiply b × c, compute all cross-products b[j]*c[k] and accumulate at position j+k. The carry at each position propagates up. This is like long multiplication in base 256.
RangeTupleCheckerBus
Unlike the carry-boolean check in ADD (where carry ∈ {0,1}), multiplication carries can be large (up to ~4×255). The (a[i], carry[i]) pair is range-checked as a tuple in a single bus interaction.
Parameters
MUL = lower 32 bits. MULH = upper 32 (signed). MULHU = upper 32 (unsigned).
AIR Structure

Constraints
  • C1 Carry equation limb 0 carry[0] = (b[0]*c[0] − a[0]) / 256 carry
  • C2 Carry equation limb 1 carry[1] = (b[0]*c[1] + b[1]*c[0] + carry[0] − a[1]) / 256 carry
  • C3 Carry equation limb 2 carry[2] = (b[0]*c[2] + b[1]*c[1] + b[2]*c[0] + carry[1] − a[2]) / 256 carry
  • C4 Carry equation limb 3 carry[3] = (b[0]*c[3] + b[1]*c[2] + b[2]*c[1] + b[3]*c[0] + carry[2] − a[3]) / 256 carry
  • C5–C8 Tuple range checks (a[i], carry[i]) sent to RangeTupleCheckerBus range
