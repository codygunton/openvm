System: Hint Store

The Rv32HintStoreAir writes external data (hints) into VM memory. It has two modes: HINT_STOREW writes a single 4-byte word, and HINT_BUFFER writes N consecutive words as a multi-row instruction. Each trace row writes one word. The hint data itself is unconstrained — any value can be written.
Key Insight: Multi-Row Instructions
HINT_BUFFER is the only RV32IM instruction that spans multiple trace rows. Each row writes one word, with rem_words counting down and mem_ptr incrementing by 4. The execution bus interaction happens only on the first row of the sequence.
Unconstrained Data
The 4-byte data columns are written to memory but have no arithmetic constraints — any value is valid. The only checks are that each byte is in [0, 256) via the BitwiseOpLookup bus. This is safe because hints are inputs the prover provides; the program logic must validate them independently.

Trace Table

Each row writes one 4-byte word to memory. Edit any cell to break constraints. 0 = satisfied, — = selector inactive, nonzero = violated. Modified cells are highlighted.

Constraint Evaluation

Transition constraints (C6-C8) only apply between consecutive buffer rows. The end constraint (C5) checks that the last row has rem_words == 1.

Bus Interactions

Memory reads happen on the first row; data writes happen on every valid row. The execution bus interaction fires once per instruction (first row only).
