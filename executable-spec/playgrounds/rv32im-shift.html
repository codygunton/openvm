RV32IM Shift

The ShiftCoreAir handles SLL (shift left logical), SRL (shift right logical), and SRA (shift right arithmetic). The shift amount is decomposed into a limb shift (whole 8-bit byte positions, 0-3) and a bit shift (intra-byte, 0-7), each encoded as one-hot markers.
Concepts
Shift Decomposition
A shift amount s is split: limb_shift = s / 8, bit_shift = s % 8. One-hot markers limb_shift_marker[4] and bit_shift_marker[8] encode these. This avoids variable exponents in constraints.
Bit Multiplier
For SLL, bit_multiplier_left = 2^bit_shift. For SRL/SRA, bit_multiplier_right = 2^bit_shift. Multiplying a limb by the bit multiplier performs the intra-byte shift. The carry between limbs captures overflow.

Constraints
  • C1 bit_shift_marker is one-hot each boolean, sum = 1
  • C2 limb_shift_marker is one-hot each boolean, sum = 1
  • C3 bit_shift recovered from marker bit_shift = Σ(i × bit_shift_marker[i])
  • C4 limb_shift recovered from marker limb_shift = Σ(i × limb_shift_marker[i])
  • C5 shift amount decomposition c[0] = limb_shift×8 + bit_shift + k×32, k range-checked
  • C6-C9 carry propagation per limb SLL: a[j]×sll = (carry_below + b[j-ls]×mul_left - 256×carry[j-ls])×sll SRL/SRA: a[j]×mul_right = (carry_above×256 + b[j+ls] - carry[j+ls])×right_shift
  • C10 SRA sign bit b_sign = MSB of b[3]; 0 when not SRA
  • C11 Opcode flags: exactly one set each boolean, sum = 1
