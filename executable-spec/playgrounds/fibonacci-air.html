Fibonacci AIR

An AIR (Algebraic Intermediate Representation) is a set of polynomial constraints over an execution trace. The trace is a matrix where each row is a computation step. Selectors control which rows a constraint applies to. If every constraint evaluates to zero on every row, the trace is valid.
