RV32IM Jump

Jump instructions change the program counter and optionally save a return address. JAL (Jump And Link) adds a 20-bit immediate to PC. JALR adds a 12-bit sign-extended immediate to a register value. LUI loads a 20-bit immediate into the upper 20 bits of a register. AUIPC adds a 20-bit upper immediate to the current PC.
Link Register
JAL and JALR save PC + 4 (the return address) into the destination register rd. The 4-byte return address is stored as 4 limbs in the register file. This is how function calls work: JAL jumps to the function and saves where to return.
Upper Immediate
LUI and AUIPC work with the upper 20 bits of a 32-bit value. LUI rd, imm sets rd = imm << 12. AUIPC rd, imm sets rd = PC + (imm << 12). The lower 12 bits are always 0 for LUI, or come from PC for AUIPC.
