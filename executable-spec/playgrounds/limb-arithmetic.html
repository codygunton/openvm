Limb Arithmetic AIR

In a STARK proof system, all arithmetic happens over a 31-bit prime field (BabyBear, p = 2013265921). But RISC-V operates on 32-bit integers. This AIR shows how 32-bit addition is implemented using 4 limbs of 8 bits each, with carry propagation between limbs.
New: Limb Decomposition

A 32-bit value is stored as 4 bytes: value = limb[0] + limb[1]×256 + limb[2]×65536 + limb[3]×16777216. Each limb is in [0, 255].

New: Carry Chain

When adding two 8-bit limbs, the result may exceed 255. The carry (0 or 1) propagates to the next limb. This chain of carries is how overflow works.
