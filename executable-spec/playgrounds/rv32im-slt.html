RV32IM Set Less Than

SLT (Set Less Than, signed) and SLTU (unsigned) compare two register values and write 1 to the destination register if rs1 < rs2, otherwise 0. Unlike branch instructions, SLT writes the comparison bit to rd rather than conditionally jumping. The AIR uses the same MSB-to-LSB diff_marker scan as BLT/BGE to find the first differing limb.
Diff Marker Scan (MSB to LSB)
To prove a < b (or a >= b), scan limbs from MSB to LSB. diff_marker[i] is a one-hot vector: it is 1 at the most significant limb where b[i] != c[i]. diff_val holds the absolute difference at that position, confirming which operand is larger.
MSB Signed Transformation (SLT only)
For signed comparison, the MSB byte is transformed: b_msb_f = b[3] - sign*256. This maps [128,255] to negative field values, so unsigned comparison of the transformed MSBs gives correct signed ordering. Range checking via the bus verifies b_msb_f + 128 is in [0,255].
