RV32IM Load Sign Extend (LB/LH)

The LoadSignExtendCoreAir handles signed byte and halfword loads. Unlike unsigned loads (LBU/LHU) which zero-extend, LB and LH replicate the most significant bit of the loaded value into the upper bytes. If the MSB is 1 (negative in two's complement), the upper bytes become 0xFF; if 0, they become 0x00.
Shifted Read Data
The adapter reads 4 bytes from memory at some aligned address. The shift amount (0-3 for LB, 0 or 2 for LH) selects which byte(s) to load. The chip pre-shifts the read data by (shift & 2) so that the core AIR only needs to handle shift=0 for LH and shift=0/1 for LB, reducing the number of opcode flags needed.
Three-Flag Design
Instead of separate flags for each shift value, the chip uses three flags: loadb_flag0 (LB with shift&1=0), loadb_flag1 (LB with shift&1=1), and loadh_flag (LH). The shift_most_sig_bit column tracks whether shift&2=2 (i.e., upper-half rotation was applied).
MSB Range Check
To verify data_most_sig_bit is correct, the chip sends most_sig_limb - data_most_sig_bit * 128 to the VariableRangeCheckerBus with a 7-bit range check. If the result is in [0, 127], the MSB claim is valid.

Constraints
  • C1 Flag booleans loadb0*(1-loadb0) = 0, loadb1*(1-loadb1) = 0, loadh*(1-loadh) = 0 all rows
  • C2 Exactly one flag (is_valid boolean) is_valid = loadb0+loadb1+loadh; is_valid*(1-is_valid) = 0 all rows
  • C3 data_most_sig_bit boolean data_msb*(1-data_msb) = 0 all rows
  • C4 shift_most_sig_bit boolean shift_msb*(1-shift_msb) = 0 all rows
  • C5 write_data[0] construction w[0] = (loadh+loadb0)*shifted[0] + loadb1*shifted[1] all rows
  • C6 write_data[1] construction w[1] = shifted[1]*loadh + (loadb0+loadb1)*limb_mask all rows
  • C7 write_data[2..3] sign fill w[2] = limb_mask, w[3] = limb_mask (where limb_mask = data_msb*255) all rows
  • C8 MSB range check (bus) most_sig_limb - data_msb*128 in [0, 127] VariableRangeChecker
