System: VM Connector

The VmConnectorAir is a tiny 2-row AIR that bookends every execution segment. Row 0 (begin) records the initial state; Row 1 (end) records the final state. It enforces that execution starts at the declared initial_pc, ends at the declared final_pc, and properly signals termination. In multi-segment proofs, the end state of segment N must match the begin state of segment N+1.
Segment Boundaries
The connector links public values (initial_pc, final_pc, exit_code, is_terminate) to trace cells. This is how the verifier knows the program ran correctly: the public values are checked against the trace.
Execution Bus Cycle
The connector sends the begin state (begin.pc, begin.ts) to start the execution chain, and receives the end state (end.pc, end.ts) from the last instruction. This closes the bus cycle.
Timestamp Range Check
Each row's timestamp is decomposed into low_limb and high_limb and range-checked via the VariableRangeCheckerBus. This constrains timestamps to be within [0, 2^timestamp_max_bits).

Constraints

    Connector Trace (2 Rows)

    Edit any trace cell to see which constraints break. Green = satisfied, red = violated. Modified cells are highlighted. The preprocessed column (prep) is read-only: 0 for row 0, 1 for row 1.

    Segment Boundary

    The connector bootstraps execution at the begin state and closes it at the end state. In multi-segment proofs, end(N) feeds into begin(N+1).

    Public Value Matching

    Each public value must match its corresponding trace cell. The exit_code match is only enforced when is_terminate = 1.

    Bus Interactions

    The connector interacts with ExecutionBus (send begin state, receive end state) and the ProgramBus (TERMINATE instruction lookup, only when is_terminate=1).

    Constraint Evaluation

    All constraints evaluated against current trace and public values. Each must equal 0 to be satisfied.
