RV32IM Branch

Branch instructions compare two register values and conditionally jump. BEQ/BNE use an inverse-witness marker technique to prove equality or inequality. BLT/BGE (and unsigned variants BLTU/BGEU) scan limbs from MSB to find the first difference, handling signed comparison by transforming the most-significant byte.
Concepts
Inverse Witness (BEQ/BNE)
To prove a != b, find the first limb where they differ and provide inv = 1/(a[i]-b[i]). The constraint cmp_eq + sum((a[i]-b[i]) * marker[i]) = 1 can only be satisfied if at least one limb differs. For a = b, all differences are 0, so no inverse exists.
MSB Signed Comparison (BLT/BGE)
For signed comparison, the MSB (most significant byte) is transformed: a_msb_f = a[3] - sign_bit * 256. This maps signed range [-128,127] to unsigned [0,255] after adding 128 offset, so unsigned comparison of transformed MSBs gives correct signed ordering.

Constraints (BEQ/BNE)
  • C1 cmp_result is boolean cmp_result × (1 − cmp_result) = 0 all rows
  • C2 When cmp_eq: all limbs equal cmp_eq × (a[i] − b[i]) = 0 for each i all rows
  • C3 Inverse witness sum cmp_eq + Σ((a[i]−b[i]) × marker[i]) = 1 all rows
  • C4 PC next to_pc = from_pc + cmp_result×imm + (1−cmp_result)×4 all rows
Constraints (BLT/BGE)
  • C1 cmp_result is boolean cmp_result × (1 − cmp_result) = 0 all rows
  • C2 cmp_lt consistency cmp_lt = cmp_result×lt_flag + (1−cmp_result)×ge_flag all rows
  • C3 MSB transformation valid (a[3]−a_msb_f) × (28−(a[3]−a_msb_f)) = 0 (and same for b) all rows
  • C4 diff_marker is one-hot or zero Σmarker[i] is boolean; each marker[i] is boolean all rows
  • C5 Prefix scan: no diff before marker (1 − prefix_sum) × diff = 0 for each limb (MSB to LSB) all rows
  • C6 At marker: diff_val matches marker[i] × (diff_val − (b[i]−a[i])×(2×cmp_lt−1)) = 0 all rows
  • C7 PC next to_pc = from_pc + cmp_result×imm + (1−cmp_result)×4 all rows
